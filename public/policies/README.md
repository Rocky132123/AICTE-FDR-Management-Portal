# Approved policy library

This folder is reserved for AICTE circulars, official rules, and approved internal SOPs that the organization is authorized to use.

No regulatory source documents are included in this prototype. Do not treat this README as a policy source. Before enabling policy Q&A/RAG in production:

1. Add verified, current source documents with document title, issuing authority, publication date, and version.
2. Extract text while preserving page/section metadata.
3. Index the text in a retrieval service and return supporting passages with each answer.
4. Require answers to cite source title and page/section; if retrieval returns no support, the assistant must say it cannot answer.
5. Keep release/refund approvals and bank authenticity verification under authorized human/workflow control.

Do not upload confidential or personal financial documents to an external LLM unless approved by the organization's security and privacy controls.
